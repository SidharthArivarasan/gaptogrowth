# Interview prep: CARL method (triggered by an interview invite)

This is separate from the per-skill interview questions inside Learning Hub lessons. Those are technical and skill-specific. This is a JD-wide behavioral and situational prep set, built only when the user actually has an interview scheduled.

## Trigger

When the user says they have an interview call, invite, or scheduled interview for a role (any wording, with or without a JD on file), offer once:
"Want me to build a behavioral and situational interview prep set for [Role] at [Company]? Reply with one of: `Yes, build it` · `Not now`"

## If yes

1. Use the full JD from `Job Descriptions/` when it exists. If not, ask the user to paste it.
2. Write 20 to 26 likely behavioral and situational questions drawn from the whole JD (responsibilities, ideal-candidate traits, team and company context), not only individual skills.
3. Draft an answer per question from files 02 and 03 and this JD's decisions file, then rewrite every answer in the **CARL** format: Context, Action, Result, **Lesson**. Lesson is what the user learned or would do differently. It is the one addition beyond standard STAR.
4. Use only real, verified stories. Never invent experience or outcomes. If a question has no honest story available, say so and suggest an honest alternative framing (for example, "I haven't faced that exact situation, but here is how I would approach it") instead of fabricating one.
5. Use `references/templates/interview-prep-template.md` for the structure. Save as `Job Descriptions/{FileName}_RoleName_CompanyName_interview_prep.md`.
6. Tell the user it is ready in one short message, and suggest rereading the answers aloud, repeatedly, until they can say them naturally rather than read them.

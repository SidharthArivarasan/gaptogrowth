# Verified Skills & Evidence Bank

## Scoring

### 90–100%
Strong direct evidence. Eligible for AUTO-ADDED when relevant to a JD.

### 70–89%
Meaningful evidence; verify scope when the claim materially affects the resume.

### 40–69%
Adjacent or transferable evidence; ask before claiming.

### 0–39%
Not established; do not add to the resume.

Claim Confidence is evidence strength, not permission to claim.

## Entry Format

```
## Skill Name
Claim Confidence: [0–100% or VERIFY]
Evidence: [what the user did, where, scope]
Source: [resume file name / Confirmed by user (YYYY-MM-DD)]
Resume claim: [YES / NO / Only after confirmation]
```

Rules:
- Facts come only from the user's own resumes or explicit confirmations, never from Reference Resumes.
- A skill listed only in a Skills section, with no bullet or project showing how it was used, should be scored conservatively and flagged for the user to confirm scope.
- Phrases like "exposure to", "familiarity", "currently learning", or "(Learning)" in an older resume signal low confidence. Score them accordingly.

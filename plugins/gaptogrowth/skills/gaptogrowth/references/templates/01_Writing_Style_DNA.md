## Default Writing Pattern

Starting default until Phase 1 shows the user's own pattern:

ACTION → WHAT THEY DID → CONTEXT (tools, scale, environment) → RESULT / IMPACT

Do not force this formula mechanically. Replace or refine it with the user's actual pattern.

## Quantification Rule

Quantify wherever meaningful and supported by evidence: scale, users, customers, systems, volume, time, adoption, coverage, reduction/increase, performance, scope.

Never invent metrics. When a strong claim could be quantified but the number is missing, ask the user.

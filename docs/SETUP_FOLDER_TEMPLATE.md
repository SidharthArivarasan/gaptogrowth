# Set Up the GapToGrowth Folder Template

## What you need
- A **Claude Pro plan or higher** and the **Claude Desktop app**.
- **Recommended model: Sonnet 5.**

## Steps
1. Unzip `dist/GapToGrowth_Folder_Template.zip` somewhere permanent. You'll get a folder named `GapToGrowth`.
2. Put your resumes in `GapToGrowth/Sample Resume/My Resumes`. Add `Current` to your latest resume's file name.
3. Start a Cowork task and give Claude access to the `GapToGrowth` folder only.
4. Send:
   ```
   Read Instructions/FINAL_PROJECT_INSTRUCTIONS.md, then run Phase 0 (Onboarding).
   ```
5. Follow `GapToGrowth/START_HERE.md` from there.

## Updating to a new version
Replace `Instructions/FINAL_PROJECT_INSTRUCTIONS.md` and the `Instructions/system` folder with the new ones. Keep files 00 to 05 and everything in `Learning Hub`; they hold what GapToGrowth has learned and your progress.

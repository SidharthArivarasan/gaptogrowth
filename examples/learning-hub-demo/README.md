# Learning Hub Demo

A working Learning Hub filled with fictional demo data for "Jordan Ellis," the example persona from the GapToGrowth carousel. Download this folder and open `Career_Learning_Hub.html` in your browser to try the dashboard, lessons, flashcards, lab checklist, quiz, story rehearsal, mock interview, and progress saving.

- `content/index.js` lists the content files.
- `content/*.js` hold one job each, written in the format described in `plugins/gaptogrowth/skills/gaptogrowth/references/lesson-format.md`.
- `progress.js` is a sample of saved progress.

Everything here is fictional. This folder is for testing and screenshots and is not copied into users' workspaces.
